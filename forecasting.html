FEATURED PROJECT

IDX30 Backtesting Analysis

Quantitative stock forecasting and investment analysis project combining technical indicators, fundamental analysis, and Pine Script backtesting.

PROJECT OVERVIEW

Technical Forecasting & Backtesting

Developed a quantitative stock forecasting and backtesting project focused on IDX30 banking sector companies by combining fundamental and technical analysis approaches.

The project utilized stock screening indicators such as Price-to-Earnings Ratio (PER) and Price-to-Book Value (PBV), alongside with SMA crossover strategies, RSI momentum indicators, Bollinger Bands, candlestick pattern recognition, and Pine Script implementation to analyze buy and sell opportunities.

Backtesting methodologies were applied to assess forecasting performance and support data-driven investment analysis and trading decision making.

TOOLS & TECHNOLOGIES

Python Pine Script Time Series Forecasting Technical Analysis Fundamental Analysis Backtesting

KEY INSIGHTS

Fundamental Stock Screening

Evaluated IDX30 banking sector stocks using PER and PBV indicators to identify fundamentally strong investment candidates.

Technical Signal Analysis

Integrated SMA crossover, RSI momentum indicators, Bollinger Bands, and candlestick patterns to evaluate market trends and trading opportunities.

Strategy Backtesting

Validated trading strategy performance through Pine Script backtesting and forecasting-based signal evaluation.
