FEATURED PROJECT

TikTok User Sentiment Analysis

Natural Language Processing project analysing TikTok user opinions and sentiment trends.

PROJECT OVERVIEW

Social Media Sentiment Analytics

Developed an NLP-based sentiment analysis project to evaluate public opinion trends related to the Jessica-Mirna case using 15,000 TikTok comments.

Implemented Random Forest classification to categorize comments into positive, negative, and neutral sentiments, achieving over 80% performance across accuracy, precision, recall, and F1-score metrics.

The analysis revealed that the majority of public sentiment tended to support Jessica Kumala Wongso, demonstrating how social media analytics can be used to understand public perception and behavioral trends.

TOOLS & TECHNOLOGIES

Python NLP Machine Learning Text Mining Sentiment Analysis Random Forest

KEY INSIGHTS

Sentiment Distribution

Majority of analyzed comments (52%) expressed positive sentiment toward Jessica Kumala Wongso, followed by neutral (36%) and negative (12%) opinions.

Model Performance

Random Forest classification achieved over 80% accuracy, precision, recall, and F1-score across sentiment categories.

NLP & Text Analytics

Applied NLP preprocessing and text mining techniques to identify sentiment patterns and interpret large-scale social media discussions.
